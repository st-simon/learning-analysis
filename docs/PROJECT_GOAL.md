# Learning Analysis：项目目标

更新日期：2026-09-20

## 产品目标

对用户逐篇提供的公开微信公众号文章 URL，可靠取得可供 ChatGPT/Codex 分析的正文。当前唯一有真实证据支持的主路线是：用户正常 Chrome 已渲染页面、一次明确授权、本机内存协调器和 Platform tunnel；不得把未经验证的 Reader 或云端抓取当作默认来源。

第一优先级不是“完全云端自动化”，而是“在不绕过站点访问控制的前提下，稳定得到可验证的文章内容”。

目标按理想程度分为：L1 GitHub开源并供少量用户本地安装；L2供用户个人在Mac/PC及ChatGPT App/Web使用；L3供用户个人在Mac及ChatGPT App/Web使用。能力建设从共同的Mac自动读取核心开始，再逐级验证Windows和外部分发。较高层级失败时不得自动降级，必须由用户确认是否接受下一层级。

三层共同硬约束：日常输入只包含公众号URL；来源受限时最多允许一次打开或授权自动提取；不得要求用户复制、粘贴、打印或上传正文。

## 第一个必须可靠的工作流

1. 用户在 ChatGPT/Codex 中提交一个 `mp.weixin.qq.com/s/...` URL。
2. 系统经 Platform tunnel 调用在线 Mac 上的本地 MCP，并为该 URL 建立有界、内存态读取请求。
3. 用户在自己的 Chrome 中正常打开文章；最小权限浏览器组件只在一次明确授权后读取已经渲染的当前页面 DOM，不自行重新请求文章。
4. 同一次读取流程自动将文章标题、来源、正文、表格、图注和图片引用交给分析层；不上传 Cookie、登录状态或浏览器凭据，也不要求用户搬运正文。
5. 任何阶段失败均返回准确阶段和原因；不回退到手工正文搬运、Cloudflare/Jina云抓取或未经验证的Reader直读。

## 一个成功输出的定义

成功结果至少包含：

- 原始来源 URL 和标题；
- 非空正文 Markdown，保留可提取的段落、表格、图注和图片引用；
- `source_channel`、`stage`、`status`、`error_code`、`characters` 和 `request_id`；
- 对缺失图片、未执行 OCR、可能截断或访问限制的明确说明；
- 无正文、验证码页和“环境异常”页不得被标记为成功。

## 约束优先级

1. 合规与安全：不绕过 CAPTCHA，不轮换代理，不伪造浏览器身份，不上传微信 Cookie。
2. 可靠性：先验证来源访问能力，再建设认证、云端或自动化。
3. 隐私：默认不在云端长期保存正文；任何跨设备正文中转需另行批准。
4. 成本：个人研究用量通常每日 3–4 篇、峰值 10 篇；目标新增经常性费用为 USD 0，任何预期正费用另行审批。
5. 体验：本地可读时保持“粘贴 URL 即分析”；被拦截时最多增加一次清晰的浏览器提取动作。
6. 人工边界：复制、粘贴、打印或上传网页正文均不属于可接受降级方案。

## 已确认事实与证据边界

- Gate 0 对 3 篇不同长度、不同图片密度的真实公众号文章达到 3/3；浏览器 DOM、本机内存桥和本地 MCP 的标题与字符数一致。
- 一篇 22,084 字文章已在 ChatGPT App/Web 经 Platform tunnel 各返回一次，且声明 `source_channel=rendered_dom`、`network_used=false`、`persistent_write=false`。
- 本地 Reader 唯一探针因 Mac TUN/Fake-IP DNS 返回 `198.18.0.0/15` 合成地址而在入口安全检查阶段停止，未进入 Jina。该结果为 `inconclusive`，不能证明 Reader 或微信访问失败；它被延期且不作为当前 L3 主路线或回退。
- Cloudflare Worker 的 OAuth/MCP 历史验证保留，但 Worker 与 Jina SaaS 路线继续冻结。
- Gate 1A-R 与 Gate 1B 提供了承重证据；正式实现 F0-F6 已进一步验证进程内capture runtime、私有扩展/token、用户级安装、App/Web两篇当前文章、约13.4秒自然登录恢复、升级轮换、零残留卸载和最终重装。

## Gate 0 验收结果

Gate 0 已于 2026-09-16 完成：H0、H2、H3a、H3b、H3c 通过；H1 为 inconclusive 并按单次上限停止。浏览器路线随后完成正式 L3 实现。

Gate 1A-R 与 Gate 1B 均已于 2026-09-18 通过。独立 L3 full-implementation proposal 于 2026-09-20 获批并完成；F0-F6 全部通过，真实文章额度严格止于2篇。

## 明确延期

- 完全云端、无人值守的公众号抓取；
- 住宅代理、IP轮换、指纹伪装或验证码自动化；
- Chrome Web Store公开分发、移动端分享扩展和跨设备正文中转；L3仅考虑个人Mac上的私有本地扩展；
- OCR、图表数值识别、图片托管、全文知识库；
- 多用户、批量爬取、付费墙或需登录内容；
- 正式替换现有插件连接。
